# Repository

mdview 官方仓库已以 Git submodule 挂在 `mdview/`，跟踪官方 `main` 上的标签 `v2.0.13`（`e6887e1adc12a55cc94acba22e513dfccbf954c4`）。

- 官方 GitHub：https://github.com/mdview2026/mdview
- 国际版网站：https://www.mdview.top/
- 中国大陆网站：https://www.mdview.cn/

作者把上述 GitHub 仓库作为 mdview 的项目地址。仓库内容是说明文档和截图，应用本体以安装包发布，源码不在该仓库中。

克隆时带上子模块：

```bash
git clone --recurse-submodules https://github.com/CCCSSSJJJ/repository.git
```

已经克隆过本仓库时：

```bash
git submodule update --init --recursive
```
